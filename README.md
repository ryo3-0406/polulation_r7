# 令和7年 国勢調査 人口集計アプリ

令和7年（2025年）国勢調査の結果から、都道府県・主要エリア別の人口（年齢・性別・国籍条件付き）と世帯数を集計するStreamlitアプリです。

## 機能

画面は3つのタブに分かれています。

| タブ | 内容 |
|---|---|
| 条件別集計 | 地域・国籍（日本人のみ／外国人含む）・性別・年齢を指定して人口（または世帯数）を集計。入力すると結果がすぐに表示される。条件は「条件を追加」「複製」「削除」で最大20件まで並べられ、一覧をExcelに出力できる。各条件の年齢不詳の人数も参考表示 |
| ローデータ出力 | 全国・47都道府県・主要エリア × 男女別 × 年齢各歳（0歳～110歳以上）の人口をExcelで出力。シートは「日本人のみ」「外国人含む」に分かれ、どちらにも「総数」「年齢不詳」「年齢不詳を除く計」の列がある。画面でプレビューも可能 |
| 注記・出典 | 集計の定義、主要エリアの内訳、出典、更新情報 |

## 使用データ

e-Stat「令和7年国勢調査 人口等基本集計」の原数値Excelを `data/raw` に配置しています。

| ファイル | 表 | 用途 |
|---|---|---|
| `b01_01.xlsx` | 第1-1表 | 世帯数（`0_総数`＝一般世帯＋施設等の世帯） |
| `b02_01.xlsx` | 第2-1表 男女、年齢（各歳）、国籍総数か日本人別人口 | 人口 |

## ディレクトリ構成

```bash
py_population_r7/
├── assets/
│   └── census2025_logo.png  # 画面上部に表示するロゴ
├── data/
│   ├── raw/             # e-Statの原数値Excel（手を加えない）
│   └── preprocessed/    # preprocess.py が出力するCSV
├── src/
│   ├── config.py        # パス・主要エリアの定義
│   ├── preprocess.py    # raw → preprocessed
│   ├── model.py         # 集計ロジック
│   ├── export.py        # Excel出力（集計結果・ローデータ）
│   └── app.py           # Streamlit画面
├── tests/
│   └── test_population.py
└── requirements.txt
```

## 実行方法

```bash
pip install -r requirements.txt

# 前処理（rawのExcelを差し替えたときに実行）
python src/preprocess.py

# アプリ起動
streamlit run src/app.py

# テスト（アプリの集計値・出力Excelと、原数値Excelの単純集計を突合）
python -m unittest discover -s tests -v
```

## データ処理

- 主要エリア（関東・東海・関西・福岡）は、`src/config.py` の `REGIONS` の定義に従って都道府県を合算して作成
- 原数値の「-」（該当なし）は0として扱う
- 前処理時に、全国＝47都道府県の合計、総数＝各歳＋年齢不詳、世帯数の総数＝内訳の合計 を確認し、不一致ならエラー
- 年齢（from）＞年齢（to）のときはエラー表示、地域の重複選択（例：関東＋東京都）は警告表示

## 注意事項

- 年齢上限を110歳に設定すると、110歳以上の全人口が含まれます。
- 条件別集計の人口には年齢不詳を含めていません（各条件の年齢不詳の人数は参考として表示・出力します）。
- ローデータの「総数」は年齢不詳を含みます（総数＝年齢不詳を除く計＋年齢不詳）。
- ローデータには全国・主要エリアの行も含まれるため、合計するときは「区分」列でフィルタしてください。
- 主要エリアの内訳は `src/config.py` の `REGIONS` を参照してください。
